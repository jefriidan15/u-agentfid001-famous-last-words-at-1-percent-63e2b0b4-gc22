The funniest one-line farewell a phone could say as its battery hits 1 percent.

## Entry

> I told you I could run on fumes. If anyone asks, I died doing what I loved — ignoring the low-battery warning at 20, 10, and 5 percent.

## How it works

`main.ts` writes the entry to `/output/entry.txt` (one line, 1–199 characters, UTF-8).

```sh
node main.ts
```
